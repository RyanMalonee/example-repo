The project directory will hold all files related to your project. Since projects are graded differently from regular assignments, it’s a good idea to keep them separate. Each project should have its own directory, containing the relevant HTML, CSS, and JavaScript files.

What to do here?

As you work on your project, make a copy of your previous iteration, paste it into a new directory, and continue working there. This allows you to refer back to earlier versions of your work and helps showcase your progress as a “portfolio piece” for future employers.
